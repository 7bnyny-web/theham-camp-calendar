# 더함캠프 홍보 캘린더

2027 더함캠프 THE PROMISE(2027. 1. 18~20, 감리교신학대학교) 홍보 일정을 보는 캘린더 앱이에요. 아이폰 기본 캘린더처럼 생겼고, 휴대폰 홈 화면에 추가해서 쓸 수 있어요.

## 기능

- 11월~1월 월 달력, 넘기면 한 달씩 맞춰 멈춤
- 날짜를 누르면 그날 할 일이 팝업으로 뜸
- 할 일 종류: 업로드, 제작, 촬영, 요청, 준비, 캠프
- 위쪽 종류를 누르면 그 종류 일정만 강조
- 중요한 일은 빨간 점으로 표시
- 완료 체크, 할 일 추가·수정·삭제

## 쓰는 곳

실제로 쓰는 앱은 claude.ai에 올라가 있어요. 수정한 내용은 claude.ai의 저장 공간에 저장돼서 여러 기기와 팀원끼리 같이 봐요.

이 저장소의 `index.html`은 앱 코드의 백업이에요. claude.ai 밖에서 열면 저장된 기본 일정을 보기 전용으로 보여 줘요.
